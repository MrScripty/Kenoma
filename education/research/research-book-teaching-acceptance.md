# Research-book teaching acceptance inventory

Feature scope: 27 canonical chapters, 95 executable worked checkpoints. Each checkpoint prescribes bounded adapter inputs and describes an observable result. Desktop uses chapter navigation, readable text and one sticky laboratory. Phones use chapter and example panels; the example remains beside a visible reading area when expanded. Manual control, keyboard focus or camera input pauses reading synchronization until the reader resumes it.

The source chapters, citations, 115 Lean declarations, original scientific kernels and recorded evidence are unchanged. The independent poser uses its existing scene/IK/skin contract. New adapter readouts and illustrations are not implementation proofs or calibrated anatomical predictions.

## Concrete failures retained as observations

- Eight material bisection iterations leave approximately 24.0254 Pa lateral residual against a 0.00001 Pa criterion. Convergence remains false.
- Eight serial-block iterations leave approximately 0.00164715 N force residual against a 1e-10 N criterion. Convergence remains false.
- The spatial example at 90 degrees and 320 iterations remains unconverged, with approximately 0.444 N maximum free force and 0.457 mm sampled penetration.
- The original anatomical trajectory still has zero accepted snapshots. Later reduced-model receipts described in the chapter do not replace that historical rejection or animate this original reference mesh.

## Review and qualification boundary

`tools/build_teaching_preview.py` accepts the locally reconstructed, checksum-verified preserved publication. It checks the pinned build manifest, original executable hashes, unchanged chapter/proof source hashes and unchanged poser source/WASM hashes, then assembles current worked readings and UI. It invokes no physical campaign, new proof compilation, remote download or publication. Old build/browser receipts are moved under `preserved-evidence`; the preview has its own source and executable manifest. The linked PDF is explicitly labelled as the preserved prior book.

The normal `npm run build` path also assembles these sequences into HTML and static Markdown. It retains the existing fresh proof and numerical gates. No new release-qualified book or new PDF is claimed by the preview. Fresh pinned Lean/Rust compilation, full book/PDF qualification and an exact-head remote workflow remain required before an approved merge/publication. No main merge, Pages deployment, PR15 change, new medical dataset or license change belongs to this feature.
