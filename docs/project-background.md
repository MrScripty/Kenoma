# Project background

Kenoma began as human mesh generation for image-diffusion reference, with three exploratory directions: connected-vertex mannequin skinning, anatomy-oriented morph targets and biomechanical pose response. Potential use in Studio Whip/Pentimento motivated the work; those integrations remain separate development goals.

The current simple posing tools are independently owned and do not implement the biomechanics research. The educational/research track develops bounded mechanics models and anatomical apparatuses with explicit evidence limits. See the [posing boundary](adr/001-simple-graph-boundary.md) and [research-book guide](../education/README.md).

The name comes from the Greek κένωμα, meaning emptiness or void, reflecting the original idea of a mannequin used as reference for an image renderer.
